# FunRuns Budapest

**Real people. Real runs. Real connections.**

We're building an authentic running community in Budapest where showing up as yourself is the only expectation. No fancy gear required, no performance metrics to prove, no Instagram filters on the experience—just people who love running and want to connect.

## What We're About

- **Authenticity first** - We're imperfect, real, and we show up anyway
- **Connection over competition** - Running is our shared language, conversation is our goal
- **All paces welcome** - From casual joggers to faster runners, everyone belongs
- **Community-driven** - We shape this together based on what people actually need

## Getting Started

### Join Us
- **Strava Group**: [FunRuns Budapest](https://www.strava.com/clubs/funruns-budapest) (link updates as needed)
- **Upcoming Runs**: Check [Issues](../../issues) for event announcements

### How to Get Involved

1. **Join a run** - Show up to the next event (check issues for dates)
2. **Share an idea** - [Open an idea issue](../../issues/new?template=idea.md) if you'd like to see something
3. **Help organize** - Comment on event planning issues to help out
4. **Spread the word** - Invite people who'd enjoy authentic connection through running
