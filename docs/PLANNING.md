# FunRuns Budapest: Plans & Vision

## The Idea

A genuine running community where people show up to connect, not perform. We're starting small and building authentically.

## Phase 1: Launch (Apr-May 2026)

**Goal**: Get people running together

- [ ] First group run (date TBD)
- [ ] Build Strava group membership
- [ ] Gather feedback on what people want
- [ ] Establish regular run schedule (e.g., weekly Thursday evening?)

**Success looks like**: 10-15 people showing up to a run and enjoying each other's company.

## Phase 2: Establish Rhythm (Jun-Aug 2026)

**Goal**: Build consistent community

- [ ] Regular weekly runs
- [ ] Different run times/locations (weekday + weekend options)
- [ ] Casual post-run meetups (coffee, park hang)
- [ ] Grow to 30+ active members
- [ ] Gather ideas for community expansion

**Success looks like**: People know when to show up and have made running friends.

## Phase 3: Deepen Connection (Sep-Dec 2026)

**Goal**: Foster real relationships beyond running

- [ ] Themed runs (scenic routes, specific neighborhoods)
- [ ] Occasional longer group runs or running adventures
- [ ] Community feedback sessions (what's working? what's not?)
- [ ] Maybe a summer running challenge (chill, not competitive)

**Success looks like**: People feel like they're part of something real, not just a running group.

## Phase 4: Sustainable Growth (2027+)

**Goal**: Keep it real while expanding

- [ ] Evaluate what's working, adjust as needed
- [ ] Consider new formats or opportunities that fit our values
- [ ] Mentor new organizers (keep it from being dependent on one person)
- [ ] Stay true to authenticity even as we grow

**Success looks like**: FunRuns Budapest is a known, trusted community where people feel genuinely welcomed.

---

## How to Use This

This roadmap is flexible. If something isn't working, we change it. If people want something different, we listen. This is our North Star, not our prison.
